Models
===

This folder contains the 3D model files used to manufacture the vehicle parts shown in the project documentation. The table below is a visual index for the model families used in the vehicle.

Some rows include more than one preview image because those files are alternate screenshots of the same part captured in different CAD programs, different views, or different revisions. That is intentional: the table groups the screenshots by physical part instead of listing every export as a separate model.

| Preview | Model name | Function |
| --- | --- | --- |
| ![Hex spacer disk](01_hex_bosluklu_daire_parca.png) ![Hex socket spacer](28_altigen_yuvali_parca.jpeg) | Hex Spacer / Socket Spacer | These parts center a shaft or connector and stop unwanted slipping. They are used wherever a hex profile is needed to keep rotation locked and stable. |
| ![Steering link arm](02_direksiyon_baglanti_kolu.png) ![Steering connector arm assembly](13_direksiyon_baglayici_kol_montaji.jpeg) ![Steering connector arm v2](19_direksiyon_baglayici_kol_v2.jpeg) ![Linkage assembly](26_baglanti_montaji.jpeg) | Steering Connector Arm | This linkage transfers servo motion into the steering mechanism. It is responsible for turning the front assembly with controlled and repeatable movement. |
| ![Long link rod](03_uzun_baglanti_cubugu.png) ![U-shaped connector](15_u_sekilli_baglanti_parcasi.jpeg) ![Long connector plate](16_uzun_baglanti_plakasi.jpeg) | Long Connector Parts | These bridge pieces keep two mounting points aligned over a longer distance. They help the steering and chassis subassemblies stay rigid while still leaving motion clearance. |
| ![Motor axle](04_motor_aksi.png) | Motor Axle | This part couples motor output to the drivetrain. It transfers torque from the motor into the wheel or gear system. |
| ![Chassis base assembly](05_sase_temeli_komple.png) ![Main body shell](08_govde_ana_tasarim.png) ![Main body variant](17_govde_ana_tasarim.jpeg) | Chassis and Body Frame | This is the main structural base of the vehicle. It supports the electronics, mounting points, and overall layout of the robot body. |
| ![Front wheel shaft](06_on_tekerlek_mili.png) ![Shaft retainer](07_mil_sabitleyici.png) ![Thin shaft](18_ince_mil.jpeg) ![Shoulder shaft](23_omuzlu_mil.jpeg) ![Short shaft](29_kisa_mil.jpeg) ![Long shaft v2](30_uzun_mil_v2.jpeg) ![Hex-base shaft](25_hex_tabanli_mil.jpeg) | Shaft and Axle Family | These shaft parts carry wheels or rotating elements and keep them aligned during motion. Different versions are used depending on length, support, and torque-transfer needs. |
| ![Steering shaft front bracket](09_direksiyon_mil_on_parca.png) | Steering Shaft Front Bracket | This bracket holds the steering shaft at the front of the vehicle. It acts as the anchor point for the direction mechanism. |
| ![Drive gear v1](10_disli_v1.png) ![Drive gear v2](11_disli_v2.png) ![Pulley disk v1](27_kasnak_disk_v1.jpeg) ![Pulley disk v2](32_kasnak_disk_v2.jpeg) ![Gear wheel v1](33_disli_cark_v1.jpeg) ![Pulley disk v3](34_kasnak_disk_v3.jpeg) ![Gear wheel v2](35_disli_cark_v2.jpeg) | Gear and Pulley Set | These transmission parts move torque between rotating components. The variants were used to test fit, ratio, engagement, and durability. |
| ![Axle assembly](12_aks_montaji.jpeg) | Axle Assembly | This is the assembled axle unit used to mount the wheels and connect the drivetrain. It shows how the axle parts work together as a complete subassembly. |
| ![L-shaped arm](20_l_sekilli_kol.jpeg) ![L-shaped link arm](24_l_sekilli_baglanti_kolu.jpeg) | L-Shaped Link Arms | These offset arms change the direction of motion between connected parts. They are useful where the linkage needs clearance or a directional shift. |
| ![Rectangular block](21_dikdortgen_blok.jpeg) ![Long round plate](22_uzun_yuvarlak_plaka.jpeg) | Support Block and Plate | These are simple support parts used for spacing, reinforcement, and load distribution. They help keep the assembly rigid and stable. |
| ![Hook arm assembly](31_kanca_kollu_montaj.jpeg) | Hook Arm Assembly | This hooked linkage is used to latch, guide, or restrain a moving element. It helps control motion in constrained sections of the mechanism. |
